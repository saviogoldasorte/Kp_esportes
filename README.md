# Kp Esportes

Catálogo web responsivo de artigos esportivos, com foco em camisas e chuteiras para campo, futsal e society.

> Projeto de portfólio: demonstra uma experiência de loja em HTML, CSS e JavaScript puro. O checkout é ilustrativo e não processa pedidos ou pagamentos.

## Demonstração

Acesse o [repositório](https://github.com/saviogoldasorte/Kp_esportes) e abra `index.html` para explorar a interface.

## Funcionalidades

- Catálogo organizado por modalidade, com preço, tamanhos e imagens dos produtos.
- Sacola com resumo de itens e subtotal.
- Fluxo demonstrativo de checkout, com telas de revisão e confirmação.
- Layout responsivo, navegação por seções e avisos acessíveis para leitores de tela.
- Formulário de novidades identificado claramente como demonstrativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript (sem dependências de build)

## Como executar

1. Clone este repositório.
2. Abra `index.html` no navegador.

O projeto não exige instalação de dependências nem servidor para a demonstração local.

## Estrutura

- `index.html`: estrutura da loja e do checkout demonstrativo.
- `styles.css` e `brand.css`: layout, responsividade e identidade visual.
- `app.js`: catálogo e interações da loja.
- `assets/`: imagens dos produtos.
